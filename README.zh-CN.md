# 轻图 0.1.0

Windows 10/11 x64 云端生图桌面工具，使用 Electron、React 和 TypeScript 开发，SQLite 保存任务，sharp 在后台线程处理图片。

## 免安装使用

完整解压 Windows portable ZIP，再双击“轻图.exe”。不要只复制 EXE，其他文件和 resources 目录都是运行必需。无需额外安装 Node.js 或 WebView2。程序未做商业代码签名，请按电脑/组织的安全策略核验来源，不要关闭系统安全保护。

1. 打开“供应商设置”，编辑预置节点，输入自己的 API Key。
2. 地址预置为 https://sub.shapantutu.com/v1 。点击“测试连接并获取模型”，勾选启用模型并保存。
3. 预置生图候选：gpt-image-2、gpt-image-2.5、gpt-image-2.5-flare、gpt-image-2.5-sunburst。最终可用性依节点返回与账户权限；模型列表可见不等于生成已实测通过。
4. “基础设置”选择保存目录和 PNG/JPG/WebP 格式；默认文本模型为内置节点的 gpt-5.6，用于主动点击“提示词优化/中译英”。可改选已启用的受支持文本模型，不与生图模型混用。
5. “生成”中新建任务，输入提示词，可加 0–8 张 PNG/JPEG/WebP 参考图；模型接口实际限制更小时按接口能力限制。选择参数后生成，等待结果返回。
6. “批量生图”中下载 XLSX 表格模板，将示例替换为提示词，每行一条，然后导入表格。读取第一个工作表第一列，可含标题“提示词”或“prompt”。空行忽略，重复提示词保留，公式单元格拒绝。最多 20 MB / 10,000 行。不支持 TXT、CSV、旧 XLS 或参考图列。

## 任务和图片

- 数量表示每条提示词期望生成的图片数，最多 4 张；普通和批量任务共享最多 5 个并发请求，超过的批量请求会排队。实际可用性仍以供应商为准。
- 生成设置提供自动、1:1、2:3、3:2、3:4、4:3、9:16 和 16:9 比例的 1K 级尺寸预设；实际请求使用面板显示的像素尺寸。自动尺寸不指定比例；从自动切换到 1K 时默认 1:1。模型可见不代表第三方节点已验证支持每种尺寸。
- 暂停只停止后续请求派发，已提交请求继续等待结果。程序关闭时会提醒在途请求风险。
- 请求结果未知不会自动重生；手动再次生成必须确认可能重复消耗。
- 下载/保存失败重试只处理已有结果，不再次调用生图接口。
- 同一任务再次生成追加一轮结果，不覆盖此前图片。清空批量列表不删除已保存文件。
- 默认命名变量支持 {序号} 和 {日期}；内部按任务、轮次、行和图片分开存放，重名不会覆盖。
- 自动保存结果后，“下载”可另存一份；放大、收藏标记、送入参考图均可使用。收藏没有额外素材库页面。
- 图片格式是真实转换；透明图转 JPG 使用白底。每张参考图最多 20 MB、单任务参考图总计最多 100 MB；结果单图最多 32 MiB，并限制解码像素数。

## 数据和隐私

任务、配置、加密 Key 存在 Windows 当前用户的应用数据目录中。免安装表示无需安装向导，不代表数据随 ZIP 文件夹移动。Key 不写入任务数据库或日志，仅向用户选定的供应商用于请求；不要把自己的数据目录打包分享。

本地不计算扣费或剩余次数；节点未提供额度查询接口时显示“暂不可查询”。没有自动换供应商或自动发送提示词优化请求。

项目仓库为 https://github.com/yuji11999/ai- 。帮助、广告跳转和更新服务尚未提供正式地址；程序不会把它们指向示例域名，也不会假称已是最新版。项目源代码许可证尚待所有者确认；所用第三方依赖遵循各自许可证。

## 源码构建

建议使用 Node.js 24。安装依赖、开发启动和不清空已有构建产物的验证命令见 [开发说明](CONTRIBUTING.md)。Windows 环境运行 npm run pack:win 可生成免安装包；打包后需要核验目标平台依赖。

开发界面时执行 `npm run dev:desktop`，会启动 Electron 和仅监听本机的 Vite 服务；修改渲染界面后会自动更新。开发版使用独立的用户数据目录，不会与普通版共享任务和供应商配置。修改 Electron 主进程或预加载代码后需要重启开发版。

`VALIDATION.txt` 和 `SOURCE_SHA256.json` 为原始交付版本的历史记录，不代表当前源码的测试结果或校验和。自动测试通过不代替真实供应商和 Windows 实机验收。
