轻图 0.1.0 原始交付验证记录

注意：以下内容记录的是原始交付版本的验证情况，源码已在交付后继续修改。测试数量、功能状态和环境结论不代表当前版本；当前开发与验证方法请参阅 README.md 和 CONTRIBUTING.md。

当前交付为首版验收包，不是已完成真实供应商全功能验证的生产结论。

代码与自动测试：
- TypeScript 类型检查、Vite 前端构建、Electron 主进程/预加载/图片工作线程构建通过。
- 当前综合自动测试 88 项通过。覆盖凭据加密存储、提交前持久化、重复提交、暂停、并发、崩溃状态恢复、跨供应商密钥隔离、限流安全重试、同步结果未知、部分结果保留、图片重下载、真实格式转换、文件非覆盖、XLSX 安全限制、文本模型配置及导航草稿合并等。
- 独立审查发现的凭据跨地址错配与下载恢复问题已修复并加入回归测试。
- 运行时依赖 npm audit 检查未报告已知漏洞；这不代表不存在未披露漏洞。

界面与集成检查：
- Linux 原生 Electron（默认沙箱）成功启动，使用隔离数据目录验证真实本地桥接、空状态、任务创建、页面切换和设置界面；没有输入真实 Key。
- 独立模拟界面检查覆盖供应商编辑、连接反馈、未知结果确认、提示词增强中途导航、默认文本模型清空及草稿保存。
- 完整核心集成测试使用模拟 HTTP，串联双图生成、真实文件保存、结果转参考图、图生图、文本翻译和 SQLite 重启恢复。

交付环境限制：
- Windows x64 已完成交叉打包和 PE/资源/目标原生依赖检查，但当前没有 Windows 10/11 实机可执行验收。
- 未使用真实 Key，未调用真实生图、图生图或文本模型，未消耗用户额度。模拟服务成功不能替代真实节点测试。
- 连接测试成功仅说明鉴权/模型列表可访问，不代表该模型已通过生成验收。
- 帮助、广告跳转、GitHub 和更新服务待提供正式地址，当前会明确提示未配置。
- 本程序未做商业代码签名。Windows 安全提示应按电脑安全策略处理，不建议关闭保护。
- 支持硬链接的文件系统采用原子非覆盖写入；FAT/exFAT 等不支持硬链接时采用独占创建且不覆盖的兼容方式，不保证文件写入过程中原子可见。

模型配置：
