# 轻图 QingTu

轻图是一个 Windows 桌面生图工具，使用 Electron、React 和 TypeScript，支持兼容 OpenAI Images 接口的供应商。任务记录保存在本机，API Key 通过 Windows 系统加密保存。

## 功能

- 单图对话：输入提示词、添加参考图，按轮次查看生成结果。
- 批量生图：下载 XLSX 模板，填写每行提示词和可选的本地参考图路径后导入；程序按队列处理。
- 输出设置：支持按序号、按日期和日期加序号命名；可按任务分目录或将所有图片集中保存在同一文件夹，同名文件自动避让。
- 数量与并发：每次请求最多 4 张图片，普通生成和批量生成共用最多 5 个并发请求。
- 图片预览：点击结果或对话中的参考图，查看原图并复制或下载。

具体使用方法、数据位置和功能限制见 [中文使用说明](README.zh-CN.md)。

## 开发

推荐 Windows 10/11 x64 和 Node.js 24。在新的空工作目录安装依赖后，运行：

```powershell
npm run dev:desktop
```

该命令启动 Electron 和仅监听本机的 Vite 开发服务；渲染界面支持热更新，修改主进程或预加载代码后需要重启。开发版使用独立的用户数据目录。

开发、验证及构建命令见 [开发说明](CONTRIBUTING.md)。
